## API 事实和边界

- Spring AI 主 API 以官方文档中的 `ChatClient` 为主；稳定使用方式、starter 命名和依赖 BOM 以选定版本文档为准。
- Docling 的 Python SDK `DocumentConverter` 是解析库接口；它本身不等于本项目的 REST API。内部端点如 `POST /internal/v1/convert` 为本项目契约，应由 OpenAPI 和契约测试维护。
- FastAPI 只承载 wrapper；不能把 Docling 的 Python 对象直接跨进程暴露给 Java。
- pgvector 近似索引牺牲精确召回换取查询速度；样本较少时先 exact，建立 HNSW 后对比 Recall@K 与时延。
- 源码和模型分别盘点。Docling 仓库 MIT 不自动覆盖每个 OCR/VLM/embedding 权重或其依赖。
